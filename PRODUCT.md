## Platform

web

## Stack

delegated: plain static HTML/CSS/JS with no framework and no npm runtime dependencies, hosted on
GitHub Pages (free, owner's account SirBepy). Map data is generated by Node scripts (built-ins
only) from the live server's region files. Chosen because the site is a handful of pages, Pages
serves static files only, and zero dependencies means zero supply-chain surface.

## Users

- **Friends of the owner (primary)**: people invited to "Los Pollos MineHermanos", on Java or
  Bedrock, who want to know how to join, what's different from vanilla, and where things are in
  the world. Most will not read paragraphs *(owner: "most people won't read: images over text,
  short")*.
- **The owner (SirBepy / Joe)**: runs the server, refreshes the map on demand, sends the link to
  new players.

## Product Purpose

The public front door for the server: the address in one glance, what the server adds over
vanilla, the optional player modpack, and a live-from-real-data biome map of the overworld.
Success = a friend can join within a minute of opening the page, and players use the map to pick
where to build or explore.

## Positioning

The map is built from the server's actual region files, not a seed: the world runs Terralith and
other worldgen datapacks, so seed-map tools (Chunkbase) show the wrong world. This site is the
only place that shows the real biomes of this world.

## Operating Context

- Server: Paper 26.3, friends-only survival, hosted on Kinetic Panel (Germany). Whitelist off.
- Java address `sirbepy.mcserver.host` (SRV record, no port). Bedrock (via Geyser)
  `eu-de-p59-a6-cg.kineticpanel.net` port `25572`. Simple Voice Chat on the server; players need
  the client mod (included in the modpack).
- Optional player modpack: `Los-Pollos-MineHermanos-26.3.mrpack` (Fabric 26.3), imported via
  Modrinth App or Prism Launcher.
- World pregenerated to about ±5000 blocks around 0,0 plus explored chunks beyond. Map data
  refreshes nightly and on demand from the live server, read-only.

## Capabilities and Constraints

- Features verified in the server repo: Towny towns (free: creation, claims, upkeep all 0),
  AuraSkills skills (`/skills`), QuickShop shops, HuskHomes 3 homes for default players plus
  `/tpa`, Bolt chest locking with SafeChests access requests, always-on Tag minigame
  (`/tag optout`), name colors (`/color`), Graves datapack, no keep-inventory, the End closed for
  now, Simple Voice Chat, Bedrock via Geyser + Floodgate.
- Nothing paid, ever. GitHub Pages limits apply (1 GB site, soft 100 GB/month bandwidth).
- Map: overworld only, no structures. Two layers: biomes (searchable) and terrain (real top
  blocks, so builds show).
- English only.

## Product Principles

1. Address first: the join info is never more than one glance away.
2. Show, don't tell: images and the map over paragraphs; every text block earns its place.
3. Real data only: the map and every feature claim trace back to the live server or its repo.
4. Free and self-maintaining: nightly refresh, nothing paid, nothing that needs babysitting.
